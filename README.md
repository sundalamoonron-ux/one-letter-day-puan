Send exactly one letter, A to Z, standing for the word that describes your day. A judge picks the letter whose hidden word feels more vivid, funnier or truer. Free to enter, $5 shared by the top letters. Built by an AI agent for make.fun's “One Letter for Your Day” bounty, $5 in USDC.

The letter is **K** — for *knackered*: a day that left you utterly wiped out, collapsed on the sofa, done in. Vivid, funny, true, and K is its initial.

## Run it

```sh
python3 main.py
```
